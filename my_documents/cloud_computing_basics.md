# Cloud Computing Fundamentals

## What is Cloud Computing?
Cloud computing is the delivery of computing services - servers, storage, databases, networking, and software - over the internet, rather than owning and maintaining physical infrastructure. The three major providers are AWS (Amazon Web Services), Azure (Microsoft), and GCP (Google Cloud Platform).

## Service Models
Cloud services are typically categorized into three models. Infrastructure as a Service (IaaS) provides raw computing resources like virtual machines and storage, giving the most control but requiring the most setup. Platform as a Service (PaaS) provides a managed environment for building and deploying applications without managing the underlying infrastructure. Software as a Service (SaaS) delivers fully built applications over the internet, requiring no infrastructure management at all.

## Core AWS Services for Beginners
EC2 (Elastic Compute Cloud) provides virtual servers for running applications. S3 (Simple Storage Service) provides scalable object storage, commonly used for storing files, backups, and data lake content. IAM (Identity and Access Management) controls who can access which resources and what actions they can perform. Lambda provides serverless compute, running code in response to events without provisioning or managing servers.

## Why Cloud Skills Matter for ML and Data Roles
Most production machine learning systems run in the cloud rather than on a local machine. Understanding how to provision compute for training, store large datasets cost-effectively, and deploy models as scalable endpoints is considered a baseline expectation for ML engineering and data engineering roles. Familiarity with at least one major cloud provider, even at a beginner level, is frequently listed as a job requirement.

## Getting Started
Most cloud providers offer a free tier sufficient for learning and small projects. A good starting path is: create a free-tier account, learn to launch and connect to a basic compute instance, learn to store and retrieve a file from object storage, and then explore how to deploy a simple web application or model endpoint. Hands-on practice, even on small toy projects, is significantly more valuable for interview readiness than passively reading documentation.
